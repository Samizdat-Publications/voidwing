# VOID WING

A 3D space combat game that runs in the browser. You fly a KV-9 Kestrel starfighter, call sign
Void One, through the Tarsus asteroid belt with two AI wingmen. Clear three waves of Hegemony
fighters, then the carrier Leviathan jumps in behind an energy shield. Knock out its four shield
generators and get clear before the chain reaction tears it apart.

## How to run

You need [Node.js](https://nodejs.org) 20 or newer.

```bash
npm install
npm run dev
```

Then open the address Vite prints (http://localhost:5173 by default) in Chrome, Edge or Firefox.
Click **Launch mission** (or press Enter) and click the game once so it can capture the mouse.

Other commands:

| Command | What it does |
| --- | --- |
| `npm run build` | Type-checks and builds a static site into `dist/` |
| `npm run preview` | Serves the built `dist/` folder |
| `npm run playtest -- --scenario win --god` | Headless self-test that flies the whole mission (see Testing) |
| `npm run assets` | Rebuilds every 3D model from the Blender scripts (needs Blender 5.1) |

## Controls

| Input | Action |
| --- | --- |
| Mouse | Aim. The ship turns toward the white steering ring |
| Left mouse (hold) | Lasers |
| Right mouse or F | Fire a missile once the lock tone goes solid and the target shows LOCK |
| W / S | Throttle up / down |
| A / D | Roll left / right |
| Shift or Space | Boost (drains the boost meter) |
| Tab | Cycle target |
| Esc or P | Pause (settings and the flight guide are in the pause menu) |

## How to play

- **Aim with the white cross, lead with the yellow dot.** The white cross shows where your guns
  point. A moving target shows a yellow lead dot: put the cross on the dot and fire.
- **Missiles** lock on by themselves while the target stays near the middle of the screen. When
  the frame closes in and the tag reads LOCK, press right mouse or F. Missiles rearm between waves.
- **Colours:** cyan is friendly, red is hostile, amber is an objective, orange is danger to you.
  Arrows at the screen edge point to things off screen, and orange chevrons around your ship show
  where incoming fire comes from.
- **Shields** recharge a few seconds after you stop taking hits. Hull damage does not.
- **The carrier:** its shield bubble stops your shots. The four generator pylons stand outside
  the bubble: destroy all four and the Leviathan comes apart. Stay clear of its flak.
- **Asteroids** split into smaller rocks when you shoot them, and hitting one hurts.
- Dying fails the mission; **Retry** restarts from the current wave.

Difficulty (Easy, Normal, Hard), mouse sensitivity, invert Y, auto-level, graphics quality and
volume are in **Settings** on the title screen and in the pause menu.

## Features

- Mouse-aim flight (point where you want to go), throttle, roll and boost; crosshair, lead
  indicator and steering ring.
- Lasers with hit feedback, and lock-on missiles with a lock tone and a cooldown.
- Razor dogfighters (fast, fight close) and Maul bombers (armoured, attack from range, shielded);
  two AI wingmen fight with you.
- Friend and foe markers, off-screen arrows, radar, target panel and a zoomed targeting-computer
  view of your current target.
- An asteroid belt with rocks that split when shot.
- A capital ship with four shield generators, flak turrets, launching fighters, and a multi-stage
  break-up and explosion.
- Engine trails, bloom, a procedural starfield and nebula, and hex-cell shield shimmer.
- HUD with hull, shields, boost, missiles, wave and objective tracker, radio messages and radar.
- Fully synthesized sound effects and music (Web Audio, no audio files).

## Graphics and performance

The game targets a steady 60 fps on a mid-range laptop. **Graphics: Auto** (the default) starts
at High and steps down a level if the frame rate stays below about 54 fps while you fly; you can
also pick High, Medium or Low yourself in Settings.

| Level | Resolution cap | Anti-aliasing |
| --- | --- | --- |
| High | device pixel ratio up to 1.5 | 4x MSAA |
| Medium | 1.0 (native CSS pixels) | 2x MSAA |
| Low | 0.75 | off |

All shaders are compiled while the loading screen is up, so the first bomber, the carrier and the
first explosion never stall a frame.

## How it is made

- **Stack:** Vite, TypeScript and Three.js (WebGL2), with an HDR post-processing chain (MSAA,
  bloom, ACES tone mapping).
- **3D models:** every model is generated by a Python script in `blender_scripts/` (one script per
  asset family) and exported to `public/assets/` as `.glb`. `npm run assets` regenerates them all
  with Blender running headless (set `BLENDER_PATH` if Blender is not in the default location).
- **Textures** are procedural: baked in Blender from shader nodes, or generated in shaders at run
  time (nebula, starfield, shields, particles).
- **Audio** is synthesized with the Web Audio API: no sound files.
- **Font:** Chakra Petch (SIL Open Font License), bundled through `@fontsource`.
- Nothing is downloaded at run time.

```
src/core      renderer, input, math
src/game      ships, AI, weapons, asteroids, capital ship, mission director, world
src/render    asset loader, camera rig, sky, particles, trails, shields, quality levels
src/audio     synthesized sound effects and the music sequencer
src/ui        HUD, menus and screens, styles
src/debug     test hooks for the Playwright self-test
blender_scripts/  one Python script per asset family
public/assets/    exported .glb models
scripts/          playtest.mjs (self-test) and build-assets.mjs
docs/             critic reports and progress screenshots from each milestone
screenshots/      final player-view screenshots
```

## Testing

`npm run playtest -- --scenario <name>` starts the game in headless Chromium, flies it with real
mouse and keyboard input, saves screenshots from the player camera and writes `report.json`
(frame rate, draw calls, console errors) to `test-output/`.

| Scenario | What it does |
| --- | --- |
| `win` | Flies the whole mission to the victory screen (add `--god` so the bot cannot die) |
| `lose` | A passive pilot that gets shot down, then presses Retry |
| `ui` | Pause menu, flight guide and settings |
| `showcase` | Boosts, then splits an asteroid close up |
| `smoke` | Loads the game and launches the mission |

Add `--preview` to test the production build. URL flags for manual testing: `?god`,
`?phase=N` (jump to a mission phase), `?seed=N`, `?quality=auto|high|medium|low`, `?nosound`.
